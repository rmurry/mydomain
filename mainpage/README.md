# rylanmurry.com

A lightweight personal landing page built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite will generate the production site in `dist/`.

## Cloudflare Pages

Connect the GitHub repository to Cloudflare Pages and use:

- Build command: `npm run build`
- Build output directory: `dist`

Then attach the custom domain `rylanmurry.com`.

## Before publishing

Update the placeholder links in `src/App.jsx`:

- `mailto:you@example.com`
- LinkedIn URL
- GitHub URL

You can also replace the sample project descriptions with real projects or case studies.
